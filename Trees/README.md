## 🌱 What is a Tree?

A **tree** is a non-linear data structure consisting of nodes connected by edges.
It represents hierarchical relationships.

Key characteristics:

* One root node
* Parent-child relationships
* No cycles

---

## 🌲 Types of Trees Covered

### 1️⃣ Binary Tree

* Each node has at most two children
* No ordering rules
* Foundation for all other tree types

### 2️⃣ Binary Search Tree (BST)

* Ordered binary tree
* Left subtree < root < right subtree
* Enables fast searching

### 3️⃣ Binary Heap

* Complete binary tree
* Used to implement priority queues
* Two types:

  * Min Heap
  * Max Heap

### 4️⃣ AVL Tree

* Self-balancing Binary Search Tree
* Height difference ≤ 1
* Guarantees O(log n) operations

### 5️⃣ Trie (Prefix Tree)

* Specialized tree for strings
* Efficient prefix searching
* Used in dictionaries and autocomplete

### 🔜 More (Future)

* Segment Tree
* Fenwick Tree (BIT)
* B-Tree / B+ Tree
